瀏覽器說「無法開啟這個資料夾」怎麼辦？

Chrome 和 Edge 不允許網頁讀取 Program Files 裡的資料夾，而爐石預設把紀錄檔放在那裡。 可以把 Logs 資料夾搬到「文件」，再在原位置放一個連結，爐石會照常寫入，網頁也能讀取。只需要做一次：

  1. 先完全關閉爐石。
  2. 在開始選單搜尋「命令提示字元」，按右鍵選「以系統管理員身分執行」，貼上下面三行（安裝位置不同請自行修改）：
robocopy "C:\Program Files (x86)\Hearthstone\Logs" "%USERPROFILE%\Documents\HearthstoneLogs" /E /MOVE
rmdir "C:\Program Files (x86)\Hearthstone\Logs"
mklink /J "C:\Program Files (x86)\Hearthstone\Logs" "%USERPROFILE%\Documents\HearthstoneLogs"
  1. 回到這個頁面，選擇「文件 › HearthstoneLogs」資料夾。

想還原時，刪除那個連結（rmdir "C:\Program Files (x86)\Hearthstone\Logs"），再把資料夾搬回去即可。 不想改的話，也可以每局結束後用「選擇 Power.log」或直接把檔案拖進這個頁面。

這是什麼？資料會上傳嗎？

這個網頁讀取爐石的 Power.log，重建每回合的戰鬥，用 TavernGym 模擬器把你的站位、指向性目標、磁力和出牌順序， 和其他所有選擇比較勝率後打分數。

所有分析都在你的電腦上（瀏覽器裡）進行，紀錄檔和報告都不會上傳到任何地方；報告只存在這個瀏覽器裡。

模擬器依 36.6.3（253932）版本建置；數值和你的客戶端不同的隨從會在報告中標出。 Hearthstone 與卡片資料為 Blizzard Entertainment 所有，本網站與 Blizzard 無關。 原始碼
